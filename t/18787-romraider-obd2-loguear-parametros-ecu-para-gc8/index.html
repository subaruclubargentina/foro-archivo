Cita

Definitions/Abbreviations
SSM : Subaru Select Monitor (4 known protocols SSM0, SSMI, SSMII, SSMIII)
ROM : Technically it is "Read Only Memory", yet it is often used to describe the whole set internal values and code that is stored on the microcontoller in the ECU which it uses to run the engine. (More information)
RS-232 : Serial communication protocol (More information)
ISO 9141-2 : OBD-2 Communication protocol (More information)
TTL Voltage Levels :
Code:
  Low (0)        High (1)        Undef.        Notes
0V to +0.8V +2V to VCC    +0.8V to +2V    VCC is +4.75V to +5.25V
RS-232 Voltage Levels :
Code:
  Low (0)        High (1)      Undef.        Notes
-3V to -15V +3V to +15    -3V to +3V    -12V low and +12V high for cars

SSM Protocol Types
SSM0
Not much known about this. Not very useful either because the cars are so old. This is for the very first fuel injected Subaru's.

SSMI
Used on Impreza's from 94 to 98
Uses TTL voltage levels
Uses a 4800 baud rate
Uses two separate lines for transmitting and receiving data

SSMII
This is very similar to OBD-2 ISO 9141-2 protocol
Used on Impreza's from 99 to 07 (not positive)
Uses RS-232 Voltage levels
Uses a 4800 baud rate
Uses a single bidirectional line for transmitting and receiving data

SSMIII
Used on Impreza's from 08 to today (not positive)
Uses CAN-BUS communication type protocol

Cita

ISO 9141-2. This protocol has an asynchronous serial data rate of 10.4 kBaud. It is somewhat similar to RS-232; however, the signal levels are different, and communications happens on a single, bidirectional line without additional handshake signals. ISO 9141-2 is primarily used in Chrysler, European, and Asian vehicles.
pin 7: K-line
pin 15: L-line (optional)
UART signaling
K-line idles high, with a 510 ohm resistor to Vbatt
The active/dominant state is driven low with an open-collector driver.
Message length is restricted to 12 bytes, including CRC

Para los que vienen leyendo y se preguntan.... emi... para que tanto quilombo??? para que me sirve esto??

Bueno con este cable, más el proyecto de software libre romraider (gracias a los desarrolladores de esta app en JAVA que también esta para LINUX!!!), más el autodiagnótico que traen los gc8 (uniendo las fichitas debajo del volante indica los códigos de error con la luz de check engine -- esto ya sería otro post) Pueden diagnosticar todos los errores que podrían ver con un scanner original de taller subaru! es más con el romraider, pueden loguear además de ver los valores en tiempo real, de hecho romraider tiene plugins para agregar WideBand al log!!

Por ejemplo pordrían hacer pruebas, tiradas,, o simplemente ir a un Speed Day y después ver en el log y saber en que parte del circuito subió la temperatura del refrigerante etc etc!

De hecho hay programitas que se encargan de filmar y agregar un monton de datos al video, como posición del auto en circuito vía GPS contar tiempos de vueltas sectores etc etc!!! estos programas también permiten alinear con el video los datos del log, de esta manera podemos ver de una forma visual e intuitiva que esta pasando con nuestro auto en cada momento de la vuelta al circuito..

Bueno teniendo el famoso cable chinito!!! que hay que hacer? voy a tratar de ir paso a paso

1) Bajar el romraider de aca: http://www.romraider.com/ (podría poner los links de los archivos directamente, pero voy a dejar que entren a la página ya que la gente que hace romraider se lo merece)

2) Bajar las definiciones de las ECU de acá http://www.romraider.com/forum/topic360.html son archivos que le van a decir al programa como identificar e interpretar cada ECU. Configurar el programa para que las utilice

3) Bajar las definiciones del logger de acá http://www.romraider.com/forum/viewtopic.php?t=1642&start=1 configurar el programa para que las use

4) Una vez configurado el romraider conectan el cable chino y asegurense de desinstalar cualquier driver de cable VAG y el SOFTWARE VCDS, ya que si bién es un cable VAG no lo vamos a usar como tal. entonces al enchufar el cable chino el sistema buscará un driver pero no lo encontrará! perfecto, entonces usamos el CD que trae en cable chino e instalamos de ahí el DRIVER GENERICO PARA EL CABLE..... no el DRIVER de Ross Tech ni el que es para VAG ni el VCDS!!! cualqueir cosa me avisan y subo este driver a algún lugar...

este driver ya se ocupa de interpretar el cable en un PUERTO COM! buenísimo!!

abrimos el romraider, entramos al logger, (no al programa para editar mapas!!) ya que no vamos a cambiar nada de la ECU solo vamos a leer!

ponemos el cable en el auto... ponemos contacto o marcha.. ponemos el cable en la PC!! Seleccionamos dentro de romraider el puerto COM correpondiente y se tiene que conectar... luego de la tabla de la izquiera eleguimos que parámetros ver..

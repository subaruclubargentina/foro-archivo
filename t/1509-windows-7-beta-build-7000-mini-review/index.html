Bueno sres.. salio (hace ya un tiempito) El beta del nuevo windows 7... el cual descargué hace 20 dias y estuve probandolo, les voy a dar un breve review..

Es un nuevo windows con un kernel creado desde 0 (a diferencia del vista.. que arrastra cosas desde el windwos 98) y viene a suplantar el no tan exitoso VISTA.

El windows lo probé en mi laptop Acer (Semprom 3500 con 2gb de ram) y les puedo decir que va muy bien.. tiene unas opciones de seguridad muy piolas (Simil OsX Leopard, el sistema operativo de Apple).. y la apariencia del vista pero mejorada

Bueno, el windows lo estuve usando con programas como el Adobe Creative Suite 4, el Office 2007 y algunos juegos como el Command and Conquer Tiberium Wars..

Este windows pareceria comportarce muy similar al vista.. en cuestiones de tiempo de arranque, y rendimiento de las aplicaciones en general.. Algunas aplicaciones muy pesadas andan similar, pero siempre mas rapidas que en el XP..

Respecto a los drivers.. utiliza las versiones de VISTA.

Lo mejor: Herramientas Administrativas mas completas, mejor control de cuentas de usuario (Funciones de usuario avazadas).. Y por finn!!! un centro de descarga de drivers online que funciona.. (todo mi hardware anda perfecto) .. Tiene un menu inicio mejorado y mas facil

Lo peor: Interfaz grafica pesada.. y si andas con programas pesados vease; photoshop, msn, azureus y muchas paginitas del internet explorer.. se empieza a alentar todo bastante, cosa q con el vista (menos en XP) pasa. Y algunas aplicaciones que andan medio raro.. Si lo piensan descargar solo les recomiendo 2 aplicaciones que no me funcionaron bien .. Internet Explorer y Windows Media Player.. que fueron suplantados por el Firefox y el Winamp ojo, no por gusto..sino pq se tornaban inestables..


Bueno.. aca les dejo un screenshot y los links de descarga para que lo prueben.. (viene como version prueba de 30 dias, pero se puede crackear)..

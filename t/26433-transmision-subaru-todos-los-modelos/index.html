Asi se interpreta...

TY856WB1AA

"T" = código de transmisión
"Y" = que es una caja de cambios manual awd
"85" = la clasificación de transmisión ... en el caso de cajas de cambios manuales este número indica la distancia entre ejes en milímetros. Las transmisiones de 6 velocidades utilizan una separación de eje de 85 mm mientras que la generación actual de transmisiones de 5 velocidades utiliza un espaciamiento de eje de 75 mm.
"6" = alguna referencia al caso de transmisión. "6" se utiliza para 6 velocidades, "4" se utiliza para 8 tornillos de 5 velocidades, "2" para 4 tornillos Impreza 5 velocidades, "5" para Forester 8-perno de 5 velocidades, "3" Para 4-pernos Forester 5 velocidades, y "7" para algunos Legacy turbo de 8 pernos de 5 velocidades.
"W" = especificación de transmisión. "W" es de 6 velocidades, "V" es de 5 velocidades, "Z" = AT con MPT, "Y" = AT con VTD, etc.
"B1AA" = indica varios detalles sobre el equipo, tales como diff central. Tipo, LSD delantero, etc. y también sobre cambios menores de la producción. "

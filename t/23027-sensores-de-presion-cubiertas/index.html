Sensores de Presion Cubiertas
« Respuesta #0 en: 21 de septiembre de 2014, 00:10 »
Buenas noches, les presento un accesorio que me funciona muy bien, informa en forma fidedigna la presion y la temperatura de las cubiertas tiene un monitor inalambrico para la consola y sensores en las cubiertas - pueden ser externos o internos - yo puse externos tienen el tamaño de un dado y hasta se pueden colocar en el auxilio, pero si donde viven hay mucho afano les sugiero ponerlos internos dentro de las llanta, las pilas duran 3 años en los sensores - son como las de reloj, y el monitor entre 3 y 6 meses.
Parece ser una buena opcion en cubiertas de perfil muy bajo donde hay menos margen para perder presion.
Ademas informa la temperatura del neumatico, para ambas cosas se se setean valores para generar una alarma audible.
El equipò se llama VITRAN y se compra por internet.
No encuentro el icono para adjuntar las fotos del equipo colocado
Saludos y espero aporte el dato.

Encontré la POSTA: sirve!

http://bbs.scoobynet.com/drivetrain-11/780378-clutch-for-impreza-turbo-gc8.html

El muchacho que preguntó es de Northampton, Inglaterra. Quería, como yo enviar su embrague desde EEUU. En la respuesta nro 13 dice (abajo lo traduzco)

Cita

Exedy USA Technical Coordinator said to me that this clutch (KSB03) is a 5 speed pull type clutch and it will directly replace the older GC chassis clutch even though it is for the GDA chassis.

The GC came with a 225mm disc, the KSB03 has a 230mm disc but will fit the GC flywheels with no issue.


Cita

El coordinador técnico de Exedy USA Technical me contó que este embrague (KSB03) es de tipo "pull" para una caja de 5 velocidades y directamente reemplazaría al embrague anterior del chásis GC, incluso siendo para el GDA.

El GC venía con un disco de 225mm, el KSB03 tiene un disco de 230mm pero encaja con el volante del GC sin ningún drama.

Si las mangueras se le ponen duras, ha tenido alguna subida de temperatura y cada tanto le falta un poco de líquido, una cosa a revisar (que generalmente se pasa por alto) es el radiador de la calefacción.
Este radiador (cuando se obstruye o tapa) dificulta la normal circulación del líquido refrigerante y puede ocasionar algunos de estos problemas.

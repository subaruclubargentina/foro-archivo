Coincido con Cla prec , yo vendo Elaion y no le echo eso a mi GT emoticon005 ahora el tema del API es relativo por ej un SL en circunstancias de friccion es similar a un SM pero este ultimo suele limpiar un poco mas el motor y protejer mas el catalizador que el SL, tengo entendido que el Havoline 20w50 SM tiene menos aditivos antifriccion que su predecesor Havo SL para que proteja los catalizadores , o sea el API mide performance general del lubricante teniendo tambien en cuenta el medio ambiente, le pondria a ojos cerrados motul o liqui API SJ a mi auto y no un SM del mercosur, ocurre a la inversa con los lubricantes para diesel que cuanto mas alto o nuevo es el API mejor proteje al motor del ollin y la friccion etc, por ej un API CI-4 plus (diesel) tiene un 30 % mas de antifriccion y 45 % mas detergente/dispersante que un mineral SM (nafta) no se si se entiende pero es muy extenso el tema de los lubricantes

SUBARU IMPREZA GT 2.0 T 4WD

MODELO 1997
KILOMETROS 165.000
a continuacion paso a detallar todos acerca del vehiculo
EXTERIOR:
Pintura/chapa intacta en exelente estado
opticas depo cristal trasnparente fondo fume/cromado( ultimas fotos ) ( se entrega tambien con opticas originales cristal rayado y corners iguales como la de las primeras fotos )
esquineros ( corners ) color ambar
faros antinieblas depo cristal transparente
aleron intermedio ( tambien se entrega con aleron alto y aleron bajo )
llantas originales rodado 15' originales homologadas para rally con cubiertas a un 80 %  205/55/15 ( se entregan con 4 cubiertas de rally pireli que me regalaron hace poco )
discos y pastillas nuevos
xenon y leds en todo el vehiculo
se le realizo un pulido / teflonado / sellado hace menos de 200 km

MOTOR / CAJA / SUSPENCION
motor 2.0 turbo
todo original, se hizo motor completo hace 5.000 km
turbo en perfecto estado
bujias iridium
caja del sti , 1ra y 2da mas cortas y rapidas ( caja para mas de 300 hp )
suspencion completa de carrera ( bastagos mas gruesos )
espirales del sti ( progresivos originales )
chapon echo a medida para cubrir la mayor zona posible
escape completo de 3'' de acero ( increible sonido )
turbo timer ( aparato que cuida el vehiculo y hace que lubrique bien el turbo antes de pararlo )
hall meter ( aparato para verificar la mezcla aire/combustible , siempre para tener un cuidado especial en el auto )

INTERIOR
butacas originales recaro ( impecable )
stereo in-dash philips ced-780 ( se entrega con stereo original del vehiculo tambien )
boofer de 12 '' con potencia de 1200w
con techo corredizo de chapa ( no vidrio )
alarma / cierre
se le realizo un mantenimiento en las puertas , se limpiaron , se lubrico y se regulo puertas y cristales

muchas cosas mas que seguramente me estoy olvidando, se dedico muy mucho tiempo plata y esfuerzo en el auto para tenerlo en el estado en el que esta!.. vale la pena!..

se recibe auto menor
cualquier consulta no molesta.

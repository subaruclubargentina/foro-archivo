    bueno.. voy a ampliar un poco.. (seguro q sixtars se copa, el siempre tiene data interesante!)

    Lo que intento es, con una unidad de control nueva para el auto.. voy a poder programar y configurarla para que mi motor modificado, pueda andar mejor, mas seguro y mas confiable que con el metodo que venia teniendo antes.. que es la cpu original + un emulador (que esto no parece alcanzar para modificaciones muy grandes) ..

    En estas ECUs podes calcular la entrega de combustible variando los pulsos de los inyectores..seria como tener un carburador con chicleres variables! Todo esto es para llegar aun parametro : la relacion aire nafta deseada.. que depende de cada situacion, la queremos distinta.. Una que no consuma mucho cuando el auto va despacio (y contamine menos) y otra cuando el motor esta acelerando para obtener maxima potencia y seguridad..!

    La Relacion Aire/Nafta, Air/Fuel Ratio o AFR es la relacion de masa de aire vs nafta que hay en el momento de la combustion! Se le dice mezcla estequiometrica cuando toda la nafta se quema con todo el aire.. Esta proporcion es 1 parte de nafta con 14.7 partes de aire..
    Una proporcion menor a 14.7 a 1 se le dice Rica, una menor pobre.

    Osea una 15/1 es una combustion pobre, una 11/1 es rica!

    Se acuerdan lo que dijo luciano antes? El Lambda? Ese factor es cuan lejos esta la combustion actual, de una estequimetrica.. un Lambda de 1.0 es estequimetrica, menor a 1 rica. Lambda es el AFR/AFR(estequeometrico)





    Lo interesante del AFR es que una combustion pobre genera mas calor que una estequeometrica, y una estequeo mas que una rica…! Entonces para mantener una temperatura de combustion “segura” para que los pistones y valvulas no se rompan.. es trabajar con combustiones ricas. Pero.. cuan ricas?

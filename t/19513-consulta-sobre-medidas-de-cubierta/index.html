Aca esta la calculadora para sacar equivalencias.

Segun tira, en 15" tenes las siguientes medidas equivalentes..

Medida        Diametro            Circunferencia      Diferencia  Veloc. Tamaño de llanta
205/60 R15  628mm / 24.72"  1973mm / 77.68"  -0.95 %    69.33  5.5x15 to 7x15
215/60 R15  640mm / 25.20"  2011mm / 79.17"  0.95 %    70.67  6x15 to 7.5x15
195/65 R15  634mm / 24.96"  1992mm / 78.43"  0.00 %    70.00  5.5x15 to 7x15

La que mas cierra es la ultima que es 100% equivalente.

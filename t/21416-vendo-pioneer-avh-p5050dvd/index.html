ESPECIFICACIONES

   50 Vatios X 4 Mosfet
   Capacidad de Reproducción de DVD-R / DVD-RW / CD-R / CD-RW
   Capacidad de Reproducción de MP3 / WMA / DIVX / JPEG (CD-R)
   Pantalla LCD Anti-Brillo con sensór de illuminación automatico
   Control Remoto
   Opciones de Illuminación: Rojo / Azul
   Equalizador Paramétrico de 3 Bandas
   PAL / PAL-M / NTSC / SECAM
   Entrada de IP Bus
   Conexión directa para iPod (Usa el CD-1200)
   Conexión directa para dispositivos USB
   Entrada para Cámara de visión trasera
   Entradas y salidas A/V
   Compatible con Controles Remoto de timón
   2 pre salidas RCA

Bueno gente vi que varios anda con ganas de mejorar sus subis asi que les paso los costos para que se den una idea de lo que se tienen que gastar

bomba walbro 255, o sea la que va $600
dosadora grande brasilera $ 350
emulador fs para poder darle mas de 1kg $ 270

Basicamente esto es lo que se necesita si quieren todo instalado, calculen $1500, lo ideal para esto es que tengan puesto un escape completo con bajada, reloj de presion de turbo y uno de mezcla. Con esto se puede dar 1.2 mas o menos.

Ademas de esto se puede instalar un sistema tipo booster para que no ande siempre con la maxima presion, ojo que lo ideal es poner algun tipo de boost control, apexi o hks, pero bue es lo que hay.

Espero que les sirva!!!!

saludos!

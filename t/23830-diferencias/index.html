          Bueno, despues de buscar un poco encontre lo siguiente:

          Series code G=Impreza S=Forester B=Legacy etc.
          Body type F=Wagon C=Sedan
          Engine type 8=2.0L Turbo
          Year code A=MY93 B=MY94 C=MY95&96 D=MY97 (facelift) E=MY98 F=MY99 G=MY00
          Number of doors 2=2 door coupe 4=4 door saloon 5=5 door wagon/hatch
          Model type 7=RA 8=WRX type E=Sti D=Sti Type R & RA S=22B
          Transmission D=5 Speed Manual AWD P=4 Speed Automatic AWD

          Y si no me equivoco, la estructura del chasis es la misma tanto en le GC6 como en el GC8, lo que cambia es el motor, suspension, frenos, etc.

          El chasis de la versión coupé no es 22B. 22B se llamó a esa edición especial, pero el código de chasis de la edición 22B es "GC8E2SD".

          Tanto el Impreza coupé como el sedán son chasis "GC".

          El "6" en GC6 refiere al viejo motor EJ25, aspirado, 4 cilindros, de 2.5lts

          En USA los viejos Impreza sólo les llegaban en modelos aspirados. La versión coupé la denominaban "2.5RS", ya que venía con el motor EJ25.

el AFC y el AFR y el SAFC son todos modulos que básicamente modifican la señal del flujometro o MAF segun las RPM y TPS (posición de la mariposa) para realizar pequeños cambios en la relacion aire nafta.. respecto a colocar un intake la verdad es q no tengo experiencia.. aunq si sigue estando el flujometro no habria problema..!

respecto a cambios de temperatura (frio o calor) no deberían de darte problemas ya que el auto viene preparado para esas contingencias...

como medir la relación aire nafta?... comprate un reloj autometer y colocalo a la zonda lambda para empezar..

y el otro modulo si.. es para variar el punto del V-tec y se que sirve para otros autos con otros sistemas para variar el cruce de arbol de levas.. lo q si no se si sirve para tu subaru

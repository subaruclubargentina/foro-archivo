Hola el VAGCOM no te sirve, ya que es solo para Vw Audi Group. Buscate una interface multimarcas comun, como el ELM327 USB (no bt porque es inestable) Y bajate un programa como el FreeSSM para subaru el Scanmaster demo, wOBD y tantos otras herramientas gratuitas. La interface ELM sale barata estan menos de 3 gambas. Si queres probar si funca, antes de comprarla, te presto la mia, no se de donde sos. Saludos!

Yo tuve tres civic y nunca tuve drama, te esta faltando efectivamente un cable en el auto que es el directo para que no se borren las memorias, este cable con el contacto apagado tiene que dar corriente, entonces conectas ahi el positivo del estereo si queres que no se apague cuando sacas las llaves.
Por otro lado algunos stereos que dicen acc en realidad son para comandar antena electrica o para atenuar el display cuando prendes las luces, esos pueden ser los cables que te sobran.
